Données publiques prêtes pour mobile

Suivre l’Assemblée nationale sans serveur à maintenir.

CitizenEye transforme les archives officielles de l’Assemblée nationale en fichiers JSON statiques, compacts et vérifiables. L’application Android télécharge uniquement ce qui change.

Voir le manifest Explorer les fichiers
manifest.json 
{
  "dataset": "citizeneye-assemblee-v17",
  "schemaVersion": 1,
  "files": [
    "deputies-<sha>.json.gz",
    "votes-<sha>.json.gz",
    "dossiers-<sha>.json.gz"
  ],
  "integrity": "sha256 verified"
}

Un backend statique pour la transparence civique.

Pas de base de données, pas de fonction cloud, pas d’API privée : uniquement des données publiques officielles compilées et servies par GitHub Pages.

Moins lourd pour le téléphone

L’app ne parse plus les grandes archives publiques dans le parcours normal. Elle lit un index par député et charge les votes utiles.

✓

Vérifiable

Chaque fichier est adressé par hash et validé en SHA-256 avant d’être utilisé par l’application Android.

↺

Résilient

Si GitHub Pages est indisponible, l’app garde son cache local puis peut revenir aux sources officielles de l’Assemblée nationale.

Pipeline public, simple, auditable.

GitHub Actions reconstruit régulièrement le jeu de données depuis les sources officielles, puis publie les fichiers statiques sur cette page.

01

Collecter

Archives députés, scrutins et dossiers législatifs depuis data.assemblee-nationale.fr.

02

Nettoyer

Normalisation des champs utiles : groupes, positions, résultats, texte parent et métadonnées.

03

Compresser

JSON stable, gzip déterministe, noms de fichiers basés sur SHA-256.

04

Servir

GitHub Pages expose le manifest et les fichiers versionnés pour le client Android.
